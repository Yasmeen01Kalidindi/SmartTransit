What is Minimum Spanning Tree?

A Minimum Spanning Tree (MST) is a subset of the network connections that connects all bus stops with the minimum possible total distance and without forming cycles.

SmartTransit can use MST algorithms to analyze how efficiently the bus network connects its stops.

🌱

Prim's Algorithm

Starts from one vertex and repeatedly adds the minimum weight edge connecting a new vertex to the existing tree.

Time Complexity: O(E log V)

🔗

Kruskal's Algorithm

Sorts all network edges by weight and adds the smallest edge that does not create a cycle.

Time Complexity: O(E log E)
